## Archived notebook edits

The archive retains the numerical logic and cached outputs. Its two Windows-specific input paths were replaced with paths relative to the notebook; one cached local report path was shortened. A new introduction identifies the archive, authorship, and calibration concern. The saved execution count and original Python metadata describe the historical run.

This archive was not overwritten with results from the refactor. Its optional Word export is preserved and requires `pandas`, `python-docx`, and a Jupyter environment in addition to the numerical packages.

## AI-assisted portfolio refactor

`src/analyze.py` keeps the same background-regression method, four-parameter Gaussian and Lorentzian models, and default analysis windows, while adding:

- Configuration-based paths and a command-line interface.
- Numeric, finite, monotonic-time, and minimum-sample checks.
- Background interpolation restricted to measured coverage.
- Detection of an unidentifiable background scale/offset.
- Positive width constraints, explicit feature polarity, and centred time for numerical fitting.
- Residual plots and a warning when both fitted half-maximum positions are not inside the selected window.
- Conditional parameter-error estimates with their limits stated.
- An optional, documented frequency calibration rather than the unverified historical default.
- Source-file hashes and environment versions in each result.

The refactor was prepared with AI assistance in September 2026. It was tested with synthetic inputs and run on the supplied measurements. Gaussian and Lorentzian widths reproduce the archived values at their reported precision.
