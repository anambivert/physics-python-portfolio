# Start here

The first complete portfolio entry is [Lab 6: Doppler-free rubidium spectroscopy](projects/rubidium-spectroscopy/README.md).

It includes your original instrument data and report, an archived notebook, reproduced plots, a portable script, and numerical checks. Its time-width fits reproduce the saved notebook values. Frequency calibration and fit-window coverage are clearly documented as remaining scientific limitations.

1. Open the project README to see the result, figure, and methods.
2. Follow [environment setup](docs/ENVIRONMENT.md) and the run commands to reproduce it.
3. Use [GitHub setup](docs/GITHUB_SETUP.md) to publish the prepared folder if it has not yet been uploaded.
4. Add your next notebook or lab using [the import guide](docs/IMPORT_EXISTING_WORK.md) or [project template](docs/ADDING_PROJECTS.md).
